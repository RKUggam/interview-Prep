1. Machine Learning Fundamentals

What is the difference between AI, machine learning and deep learning?

AI is the broad field of building systems that perform tasks requiring human intelligence (including rule-based systems). ML is a subset of AI where systems learn patterns from data instead of being explicitly programmed. Deep learning is a subset of ML that uses multi-layer neural networks to learn features automatically from raw data.

What is machine learning? How does it differ from traditional programming?

ML is the study of algorithms that improve at a task through experience (data) rather than explicit rules. In traditional programming, humans write rules: data + rules → output. In ML, the algorithm learns rules: data + output → rules (model).

What are features, labels and samples? Structured vs unstructured data?

A feature is an input variable (age, pixel value, word count); a label/target is what we want to predict; a sample/instance is one row/example, represented as a feature vector. Structured data is tabular (rows and columns, databases, spreadsheets). Unstructured data has no fixed schema (text, images, audio, video). Semi-structured data has some structure (JSON, XML, logs).

What is the difference between training and inference?

Training learns model parameters from historical data; it is compute heavy and usually done offline. Inference (prediction/scoring) applies the trained model to new data; latency, throughput and cost matter most here.

Give real-world applications of machine learning.

Spam filtering, product/movie recommendations, fraud detection, credit scoring, demand and sales forecasting, customer churn prediction, medical image diagnosis, speech recognition, machine translation, face recognition, self-driving car perception, predictive maintenance, search ranking, and dynamic pricing.

What are the main types of machine learning?

  • Supervised: labeled data; classification and regression.
  • Unsupervised: unlabeled data; clustering, dimensionality reduction, density estimation.
  • Semi-supervised: few labels + many unlabeled samples (pseudo-labeling, consistency regularization).
  • Self-supervised: labels derived from data itself (masked tokens, next token, contrastive views).
  • Reinforcement learning: agent learns via rewards from interacting with an environment.

Classification vs regression?

Classification predicts discrete categories (spam / not spam); regression predicts continuous values (house price). Some problems can be framed either way (e.g., ordinal ratings).

Explain the bias-variance trade-off.

Expected error = Bias² + Variance + Irreducible noise. Bias is error from overly simple assumptions (underfitting). Variance is sensitivity to fluctuations in training data (overfitting). Increasing model complexity lowers bias but raises variance; the goal is the sweet spot minimizing total error. Regularization, more data, and ensembling help manage it (bagging reduces variance; boosting reduces bias).

What are overfitting and underfitting? How do you detect and fix them?

Overfitting: low training error, high validation error. Fix: more data, augmentation, regularization (L1/L2, dropout), simpler model, early stopping, feature selection, ensembling, cross-validation.
Underfitting: high training and validation error. Fix: more complex model, more/better features, less regularization, train longer.
Detect via learning curves (train vs validation error as data/epochs grow).

Why split data into train, validation and test sets?

Train: fit parameters. Validation: tune hyperparameters / model selection / early stopping. Test: final unbiased estimate of generalization, touched only once. Using the test set for tuning leaks information and gives optimistic estimates. Typical splits: 70/15/15 or 80/10/10; for big data, 98/1/1 is fine.

What is cross-validation? Describe its variants.

  • k-fold: split into k folds; train on k-1, validate on 1, rotate; average scores.
  • Stratified k-fold: preserves class proportions in each fold (important for imbalance).
  • Leave-one-out (LOOCV): k = n; low bias, high variance, expensive.
  • Group k-fold: same group (e.g., patient/user) never appears in both train and validation.
  • Time-series split (forward chaining): train on past, validate on future only.
  • Nested CV: inner loop tunes hyperparameters, outer loop estimates performance.

What is data leakage? Give examples.

When information not available at prediction time leaks into training, producing overly optimistic results. Examples: scaling/imputing using statistics of the full dataset before splitting; features derived from the target (e.g., "account_closed_date" when predicting churn); future data in time series; duplicate records across train/test; same patient in train and test. Prevent with pipelines fit only on training folds, time-aware splits, group splits, and careful feature audits.

What is the curse of dimensionality?

As dimensions grow, data becomes sparse, volume grows exponentially, distances become less discriminative (nearest and farthest neighbors become nearly equidistant), and you need exponentially more data to cover the space. It hurts distance-based methods (KNN, k-means). Mitigate with feature selection, dimensionality reduction (PCA), regularization, and domain knowledge.

Parametric vs non-parametric models?

Parametric: fixed number of parameters regardless of data size (linear/logistic regression, Naive Bayes, neural nets of fixed size); strong assumptions, fast, less data needed. Non-parametric: complexity grows with data (KNN, decision trees, kernel SVM, Gaussian processes); flexible but needs more data and can overfit.

Generative vs discriminative models?

Discriminative models learn P(y|x) or a decision boundary directly (logistic regression, SVM, neural classifiers). Generative models learn P(x, y) or P(x) and can generate samples (Naive Bayes, GMM, HMM, VAE, GAN, diffusion, LLMs). Discriminative usually gives better classification accuracy with enough data; generative handles missing data, works with fewer samples, and can synthesize data.

What is the No Free Lunch theorem?

Averaged over all possible problems, no learning algorithm outperforms another. Hence model choice must be guided by assumptions about the specific problem (inductive bias) and empirical validation.

What is inductive bias?

The set of assumptions a learner uses to generalize beyond training data. Examples: linear regression assumes linearity; CNNs assume locality and translation equivariance; RNNs assume sequential structure; KNN assumes nearby points share labels; Transformers have weak inductive bias and therefore need more data.

What is the difference between a parameter and a hyperparameter?

Parameters are learned from data during training (weights, biases, split thresholds). Hyperparameters are set before training and control the learning process (learning rate, number of trees, depth, regularization strength, batch size, k in KNN).

What is the difference between a loss function, a cost function and an objective function?

Loss: error for a single example (e.g., squared error). Cost: average loss over the dataset, often plus a regularization term. Objective: any function being optimized, minimized or maximized (e.g., maximizing likelihood). In practice the terms are often used interchangeably.

What is a baseline model and why build one first?

A simple reference model: majority class, mean/median prediction, naive forecast (last value), simple rules, or plain logistic/linear regression. It sets the minimum bar, shows whether ML adds value, justifies extra complexity, and helps catch bugs or leakage (a complex model that barely beats, or suspiciously crushes, the baseline needs investigation).

What is regularization and why is it used?

Any technique that constrains model complexity to reduce overfitting: L1/L2 penalties, dropout, early stopping, data augmentation, weight decay, pruning trees, max depth, label smoothing, noise injection. It trades a bit of bias for a large reduction in variance.

What is the difference between online learning and batch learning?

Batch (offline) learning trains on the full dataset at once and is retrained periodically. Online learning updates the model incrementally as each sample/mini-batch arrives (SGD, streaming); useful for non-stationary data and data that does not fit in memory, but sensitive to noise and needs learning-rate control.

Which Python libraries are commonly used for ML and DL?

NumPy (arrays, linear algebra), pandas (tabular data manipulation), Matplotlib/Seaborn/Plotly (visualization), SciPy and statsmodels (statistics, tests, classical models), scikit-learn (classical ML, preprocessing, pipelines, metrics), XGBoost/LightGBM/CatBoost (boosting), PyTorch and TensorFlow/Keras (deep learning), OpenCV (vision), NLTK/spaCy/Hugging Face Transformers (NLP), MLflow (experiment tracking).

How would you approach a new ML problem end to end?

  1. Understand the business goal and define success metrics (business + ML metric).
  2. Check if ML is needed; establish a simple baseline/heuristic.
  3. Collect data, understand labels, check quality, EDA.
  4. Split data correctly (time/group aware) to avoid leakage.
  5. Feature engineering and preprocessing in a pipeline.
  6. Train simple models first, then more complex ones; tune with CV.
  7. Error analysis; iterate on data and features.
  8. Evaluate on held-out test; check fairness, robustness, latency.
  9. Deploy, monitor drift and performance, retrain.

How do you choose which algorithm to use?

Consider the problem type (classification, regression, clustering), data size and type, need for interpretability, latency/memory limits, linearity of relationships, number of features and missing values. Rules of thumb: tabular → gradient boosting / random forest (logistic/linear regression as a baseline); images → CNNs/ViTs; text → Transformers (TF-IDF + linear model as a baseline); small data → simpler, regularized models; need explanations → linear models or shallow trees. Start simple and let cross-validation decide.

What is semi-supervised learning? Name some techniques.

Learning from a small labeled set plus a large unlabeled set. Techniques: self-training / pseudo-labeling, co-training, consistency regularization (FixMatch, Mean Teacher), label propagation on graphs, and pretraining with self-supervision followed by fine-tuning.

What is active learning?

The model chooses which unlabeled samples should be labeled next, typically the most informative (uncertainty sampling, query-by-committee, expected model change, diversity sampling). Reduces labeling cost.

What is transfer learning?

Reusing knowledge from a model trained on a source task/domain for a target task: use pretrained weights as a feature extractor or fine-tune some/all layers. Very effective when target data is limited (ImageNet CNNs, BERT, LLMs).

What is multi-task learning and meta-learning?

Multi-task learning: one model trained jointly on related tasks with shared representations, improving generalization via shared signal. Meta-learning ("learning to learn"): train across many tasks so the model adapts quickly to new tasks with few examples (MAML, prototypical networks). Related: few-shot and zero-shot learning.

2. Statistics, Probability & Math

What are conditional, joint and marginal probability? Independent vs mutually exclusive events?

Joint P(A, B): both occur. Marginal P(A): sum/integrate the joint over other variables. Conditional P(A|B) = P(A, B)/P(B): probability of A given B occurred. Independent events: P(A, B) = P(A)P(B), so knowing one tells nothing about the other. Mutually exclusive: cannot occur together, P(A, B) = 0; such events (with non-zero probability) are therefore dependent.

State Bayes' theorem and give an ML use.

P(A|B) = P(B|A) · P(A) / P(B). Posterior = likelihood × prior / evidence. Used in Naive Bayes classifiers, Bayesian inference, MAP estimation, Bayesian optimization, spam filtering, and medical test interpretation.

MLE vs MAP estimation?

MLE chooses parameters maximizing P(data | θ). MAP maximizes P(θ | data) ∝ P(data | θ)P(θ), i.e., MLE plus a prior. A Gaussian prior on weights gives L2 regularization; a Laplace prior gives L1. With infinite data, MAP converges to MLE.

Why is minimizing MSE equivalent to MLE under Gaussian noise, and cross-entropy to MLE for classification?

If y = f(x) + ε, ε ~ N(0, σ²), the negative log-likelihood is proportional to Σ(y − f(x))², so MLE = least squares. For Bernoulli/categorical labels, the negative log-likelihood is exactly binary/categorical cross-entropy.

Common probability distributions you should know?

Bernoulli (single binary trial), Binomial (# successes in n trials), Poisson (count of events per interval), Geometric, Uniform, Normal/Gaussian, Exponential (time between events), Beta (probabilities; conjugate to Bernoulli), Dirichlet (multinomial prior; used in LDA), Multinomial/Categorical, Student-t (heavier tails), Chi-squared, Log-normal.

Mean vs median vs mode? What are variance, standard deviation, skewness and kurtosis?

Mean: average, sensitive to outliers. Median: middle value, robust; preferred for skewed data (income, house prices). Mode: most frequent value; useful for categorical data. Variance: average squared deviation from the mean; standard deviation is its square root, in the original units. Skewness: asymmetry (right-skewed: mean > median). Kurtosis: heaviness of tails / outlier proneness.

What are the properties of the normal distribution?

Symmetric and bell-shaped; mean = median = mode; fully defined by μ and σ. Empirical rule: ~68% of data within 1σ, ~95% within 2σ, ~99.7% within 3σ. Standardize with z = (x − μ)/σ. Check normality with histograms, Q-Q plots, or Shapiro-Wilk / Kolmogorov-Smirnov tests.

What are common sampling techniques?

Simple random (every item equally likely), stratified (sample within subgroups to preserve proportions; used for train/test splits on imbalanced data), cluster (randomly select whole groups), systematic (every k-th item), and convenience sampling (easy but biased). Over/undersampling adjusts class balance.

Population vs sample? Standard deviation vs standard error?

The population is the full group of interest; a sample is a subset used to estimate population parameters (sample variance divides by n − 1 for an unbiased estimate). Standard deviation measures spread of individual data points. Standard error measures the uncertainty of an estimate such as the sample mean: SE = σ/√n, shrinking as sample size grows; it is used to build confidence intervals and test statistics.

What is the Central Limit Theorem and why does it matter?

The distribution of the sample mean of i.i.d. variables with finite variance approaches a normal distribution as sample size grows, regardless of the original distribution. It justifies confidence intervals, z/t-tests, and A/B test statistics.

Law of large numbers?

As the number of i.i.d. samples grows, the sample average converges to the expected value. Underlies Monte Carlo estimation and the use of empirical risk to approximate expected risk.

Explain hypothesis testing, p-value, Type I and Type II errors, and statistical power.

Null hypothesis H0 (no effect) vs alternative H1. p-value: probability of observing data at least as extreme as seen, assuming H0 is true. Reject H0 if p < α (e.g., 0.05). Type I error (false positive): rejecting a true H0, rate α. Type II error (false negative): failing to reject a false H0, rate β. Power = 1 − β, increases with sample size and effect size.

When do you use a z-test, t-test, chi-square test or ANOVA?

  • z-test: compare means with known population variance or large samples; compare proportions (A/B conversion rates).
  • t-test: compare means with unknown variance / small samples; one-sample, two-sample (independent) or paired.
  • Chi-square test: categorical data; goodness-of-fit or independence between two categorical variables (also used for feature selection).
  • ANOVA: compare means across 3+ groups (F-test).
  • Non-parametric alternatives when normality fails: Mann-Whitney U, Wilcoxon signed-rank, Kruskal-Wallis.

What is a confidence interval?

A range computed from data such that, under repeated sampling, X% of such intervals contain the true parameter. It is not the probability the parameter lies in this particular interval (that is a Bayesian credible interval).

How do you design and analyze an A/B test?

Define the hypothesis and primary metric; choose α, power, minimum detectable effect; compute sample size; randomize users (unit of randomization); run for full business cycles; avoid peeking (or use sequential testing); check sample ratio mismatch; analyze with t-test / z-test for proportions / bootstrap; account for multiple comparisons (Bonferroni, FDR); consider novelty effects and network effects.

Correlation vs causation? Pearson vs Spearman?

Correlation measures association; causation means changing X changes Y. Confounders, reverse causality, and selection bias can create correlation without causation; establish causality with randomized experiments or causal inference (instrumental variables, diff-in-diff, propensity scores). Pearson measures linear correlation; Spearman measures monotonic rank correlation and is robust to outliers.

Covariance vs correlation?

Covariance measures joint variability and depends on units/scale. Correlation is covariance normalized by the product of standard deviations, bounded in [−1, 1] and unitless.

What are entropy, cross-entropy and KL divergence?

Entropy H(p) = −Σ p log p: uncertainty of a distribution. Cross-entropy H(p, q) = −Σ p log q: expected bits to encode p using q. KL divergence KL(p||q) = Σ p log(p/q) = H(p, q) − H(p) ≥ 0; asymmetric, measures how q differs from p. Minimizing cross-entropy w.r.t. q is equivalent to minimizing KL since H(p) is constant. JS divergence is a symmetric, bounded version.

What is mutual information?

I(X;Y) = H(X) − H(X|Y): reduction in uncertainty about X from knowing Y. Zero iff independent; captures non-linear dependencies. Used for feature selection and in decision trees (information gain).

What is the bootstrap?

Resampling the dataset with replacement many times to estimate the sampling distribution of a statistic (confidence intervals, standard errors). Also the basis of bagging. About 63.2% of unique samples appear in each bootstrap sample.

Key linear algebra concepts for ML?

Vectors, matrices, dot product (similarity), matrix multiplication, transpose, inverse, rank, eigenvalues/eigenvectors (PCA, stability), SVD (PCA, recommender systems, low-rank approximation, LoRA), positive (semi-)definite matrices (covariance, convexity via Hessian), norms (L1, L2, Frobenius), orthogonality, projections.

What are eigenvalues and eigenvectors? Where are they used in ML?

For a square matrix A, an eigenvector v is a non-zero vector whose direction is unchanged by A: Av = λv, where the eigenvalue λ is the scaling factor. In PCA, eigenvectors of the covariance matrix are the principal directions and eigenvalues are the variance along them. Also used in spectral clustering, PageRank, analyzing Hessians (convexity) and RNN stability.

Key calculus concepts for ML?

Derivatives and partial derivatives, gradient (direction of steepest ascent), chain rule (backpropagation), Jacobian (vector-valued functions), Hessian (curvature; second-order optimization, convexity check), Taylor expansion (justifies gradient descent and Newton's method).

What is a convex function and why does it matter?

f is convex if the line segment between any two points lies above the graph (Hessian PSD). Any local minimum is global, so gradient methods converge to the optimum. Linear/logistic regression and SVM objectives are convex; neural network losses are non-convex.

What is the difference between probability and likelihood?

Probability: parameters fixed, data varies; P(data | θ). Likelihood: data fixed, viewed as a function of parameters; L(θ | data). Likelihood is not a probability distribution over θ.

What is the i.i.d. assumption and why can it fail?

Independent and identically distributed: samples are drawn independently from the same distribution. It fails for time series (autocorrelation), grouped data (same user), and distribution shift between train and production, which invalidates naive CV and generalization estimates.

What are Simpson's paradox and selection bias?

Simpson's paradox: a trend appearing in groups reverses when groups are combined, due to a confounder. Selection bias: the sample is not representative of the population (survivorship bias, non-response), causing models to fail in production.

How do you estimate a causal effect when an A/B test isn't possible? What is uplift modeling?

Randomized experiments are the gold standard. With observational data use: propensity score matching/weighting (balance treated and control on observed covariates), difference-in-differences (compare changes over time against a control group), regression discontinuity (units just above vs below a cutoff), instrumental variables, and synthetic control. All rely on assumptions such as no unmeasured confounding. Uplift modeling predicts the incremental effect of a treatment for each individual, P(y | treated, x) − P(y | control, x), using T-/S-/X-learners or causal forests, so you target "persuadable" customers rather than those who would convert anyway.

What is survival analysis?

Modeling time until an event (churn, machine failure, death) when some observations are censored (the event hasn't happened yet by the end of observation). Tools: Kaplan-Meier estimator (survival curve), log-rank test (compare groups), Cox proportional hazards model (hazard ratios for features; assumes proportional hazards), and ML variants such as random survival forests and XGBoost with AFT/Cox objectives. Evaluated with the concordance index (C-index).

3. Data Preprocessing & Feature Engineering

What steps do you follow in Exploratory Data Analysis (EDA)?

  1. Understand the dataset: shape, data types, meaning of columns and the target.
  2. Summary statistics; missing values; duplicates; inconsistent or invalid values.
  3. Univariate analysis: distributions (histograms, box plots), skewness, outliers, class balance.
  4. Bivariate/multivariate analysis: correlation heatmap, scatter plots, feature vs target relationships, categorical cardinality.
  5. Time trends and seasonality if data is temporal.
  6. Flag possible leakage features and form hypotheses for feature engineering.

How do you handle missing values?

First understand the mechanism: MCAR (completely at random), MAR (depends on observed data), MNAR (depends on the missing value itself). Options: drop rows/columns (if few or useless), mean/median/mode imputation, constant + "missing" indicator flag, KNN imputation, iterative/MICE (model-based), forward/backward fill for time series, or use models that handle NaNs natively (XGBoost, LightGBM). Fit imputers on training data only.

Normalization vs standardization? When is scaling needed?

Min-max normalization: (x − min)/(max − min) → [0, 1]; sensitive to outliers. Standardization (z-score): (x − μ)/σ → mean 0, std 1. Robust scaling: uses median and IQR. Scaling matters for gradient-based models, distance-based methods (KNN, k-means, SVM), PCA and regularized models. Tree-based models are scale-invariant.

How do you encode categorical variables?

  • One-hot: nominal, low cardinality.
  • Label/ordinal encoding: ordinal categories, or tree models.
  • Target/mean encoding: high cardinality; use out-of-fold + smoothing to avoid leakage.
  • Frequency/count encoding.
  • Hashing trick: very high cardinality, fixed dimension.
  • Embeddings: learned dense vectors in neural nets.
  • CatBoost uses ordered target statistics natively.

What is the dummy variable trap?

With one-hot encoding of k categories plus an intercept, the k columns always sum to 1, causing perfect multicollinearity in linear models. Fix: use k − 1 dummy columns (drop_first=True). Not an issue for tree models and less of one with regularization.

How do you detect and handle outliers?

Detect: box plots / IQR rule (outside Q1 − 1.5·IQR, Q3 + 1.5·IQR), z-score > 3, Mahalanobis distance, isolation forest, LOF, DBSCAN. Handle: verify if error or genuine; remove, cap/winsorize, log/Box-Cox transform, use robust models/losses (Huber, MAE, trees), or treat as separate signal (fraud).

How do you handle imbalanced datasets?

  • Use proper metrics: precision, recall, F1, PR-AUC instead of accuracy.
  • Resampling: random oversampling, undersampling, SMOTE/ADASYN (on training data only).
  • Class weights / cost-sensitive learning (class_weight='balanced', scale_pos_weight).
  • Threshold tuning on the validation set.
  • Focal loss for deep learning; ensembles like balanced random forest / EasyEnsemble.
  • Anomaly detection framing when positives are extremely rare.
  • Collect more minority data.

What is SMOTE?

Synthetic Minority Over-sampling Technique: for a minority sample, pick one of its k nearest minority neighbors and create a synthetic point on the line segment between them. Reduces overfitting vs duplicate oversampling, but can create noise near class boundaries and doesn't work well for high-dimensional/categorical data. Apply only inside training folds.

What are feature selection methods?

  • Filter: statistical scores independent of model (correlation, chi-square, ANOVA F-test, mutual information, variance threshold).
  • Wrapper: search subsets using model performance (forward selection, backward elimination, RFE).
  • Embedded: selection during training (L1/Lasso, tree feature importance).

Benefits: less overfitting, faster training, interpretability.

Feature selection vs feature extraction?

Selection keeps a subset of the original features, preserving interpretability (Lasso, RFE, mutual information). Extraction creates new features by transforming or combining existing ones (PCA, LDA, autoencoders, embeddings); can capture more information in fewer dimensions but new features are harder to interpret.

What is multicollinearity and how do you detect and handle it?

High correlation among features. It inflates coefficient variance in linear models, making coefficients unstable and hard to interpret (predictions may still be fine). Detect with correlation matrix and Variance Inflation Factor (VIF > 5–10). Handle by dropping/combining features, PCA, or Ridge regularization.

Why apply log or power transforms?

To reduce right skew, stabilize variance, make relationships more linear, and lessen outlier impact. Examples: log(1+x), square root, Box-Cox (positive data), Yeo-Johnson (any sign). Also used on targets like price, then exponentiated back.

What feature engineering techniques do you know?

Binning/discretization, polynomial and interaction features, ratios and differences, aggregations (group-by mean/count/std per user), date-time features (hour, weekday, holiday, cyclical sin/cos encoding), lag and rolling-window features, text features (TF-IDF, embeddings), geospatial features (distance, clusters), domain-specific features, target encoding.

Why use cyclical encoding for time features?

Hour 23 and hour 0 are adjacent but numerically far. Encoding as sin(2π·h/24) and cos(2π·h/24) preserves circular continuity.

How should preprocessing be applied to train and test sets?

Fit transformers (scalers, imputers, encoders, PCA) on training data only, then transform validation/test with those fitted parameters. Use pipelines (e.g., scikit-learn Pipeline/ColumnTransformer) so the same steps run in each CV fold and in production.

What is the difference between fit, transform and fit_transform?

fit learns parameters from data (e.g., mean and std for a scaler, vocabulary for a vectorizer). transform applies the learned parameters to data. fit_transform does both in one step and should be used only on training data; validation, test and production data must use transform only, otherwise information leaks.

How do you deal with high-cardinality categorical features?

Target encoding with smoothing and out-of-fold computation, frequency encoding, grouping rare categories into "Other", hashing, learned embeddings, or CatBoost's native handling. Avoid one-hot explosion.

What is data augmentation? Give examples across modalities.

Creating modified copies of data to increase diversity and reduce overfitting. Images: flips, crops, rotation, color jitter, cutout, mixup, cutmix. Text: synonym replacement, back-translation, random deletion, paraphrasing with LLMs. Audio: time-shift, pitch shift, noise, SpecAugment. Tabular: SMOTE, noise injection.

How do you handle noisy labels?

Label auditing and relabeling, consensus of multiple annotators, confident learning (cleanlab) to find mislabeled samples, robust losses (MAE, symmetric CE), label smoothing, co-teaching, early stopping (nets memorize noise late).

4. Linear & Logistic Regression

Explain linear regression.

Models the target as a linear combination of features: ŷ = β0 + β1x1 + ... + βpxp. Parameters are fit by minimizing the sum of squared residuals (Ordinary Least Squares), via the normal equation or gradient descent. Simple regression has one feature; multiple regression has many. Fast, interpretable, and a strong baseline; evaluated with RMSE, MAE and R².

What are the assumptions of linear regression?

  1. Linearity between features and target.
  2. Independence of errors.
  3. Homoscedasticity (constant error variance).
  4. Normality of residuals (for inference).
  5. No (perfect) multicollinearity.

Check with residual plots, Q-Q plots, Durbin-Watson test, VIF.

What is the closed-form (normal equation) solution of linear regression? When not to use it?

β = (XTX)−1XTy. Cost is O(n·d² + d³); impractical for many features or when XTX is singular (multicollinearity, d > n). Use gradient descent, QR/SVD, or Ridge, which gives (XTX + λI)−1XTy and is always invertible.

Explain R² and adjusted R².

R² = 1 − SSres/SStot: fraction of target variance explained. It never decreases when adding features. Adjusted R² = 1 − (1 − R²)(n − 1)/(n − p − 1) penalizes extra features. R² can be negative on test data if the model is worse than predicting the mean.

How do you check whether a feature is significant in linear regression?

Each coefficient has a t-statistic (β/SE(β)) and p-value testing H0: β = 0; p < 0.05 suggests the feature is significant. The F-test checks whether the model as a whole (or a group of features) is significant. Confidence intervals that exclude 0 tell the same story. Multicollinearity inflates standard errors and can hide significant features.

How do you interpret coefficients in linear regression?

βj is the expected change in y for a one-unit increase in xj, holding other features constant. With standardized features, magnitudes are comparable. With log target, coefficients approximate percentage change. Multicollinearity makes interpretation unreliable.

What is logistic regression? Why is it called regression?

A linear classifier modeling the log-odds as linear: log(p/(1−p)) = wTx + b, so p = σ(wTx + b) with the sigmoid σ(z) = 1/(1+e−z). It "regresses" the probability (log-odds) and is a GLM with a logit link. The decision boundary is linear.

What is the loss function of logistic regression and why not MSE?

Binary cross-entropy (log loss): −[y log p + (1−y) log(1−p)]. It is the Bernoulli negative log-likelihood and is convex in w. MSE with sigmoid is non-convex and yields small gradients when predictions are confidently wrong.

How do you interpret logistic regression coefficients?

A one-unit increase in xj changes the log-odds by βj, i.e., multiplies the odds by eβj (odds ratio).

How does logistic regression handle multi-class problems?

One-vs-Rest (train K binary classifiers) or multinomial (softmax) regression: pk = ezk/Σezj, trained with categorical cross-entropy.

What happens with perfectly separable data in logistic regression?

The MLE does not exist: weights grow to infinity to push probabilities to 0/1. Regularization fixes this.

What are polynomial regression and GLMs?

Polynomial regression adds powers/interactions of features and is still linear in parameters. Generalized Linear Models connect a linear predictor to the mean of an exponential-family distribution through a link function: linear (identity, Gaussian), logistic (logit, Bernoulli), Poisson regression (log, counts), Gamma regression.

What is heteroscedasticity and how to fix it?

Non-constant residual variance (e.g., errors grow with predicted value). Coefficients remain unbiased but standard errors are wrong. Fix with transforming the target (log), weighted least squares, or robust (Huber-White) standard errors.

What are robust regression methods?

Methods less sensitive to outliers: Huber loss (quadratic near zero, linear far away), MAE / quantile regression, RANSAC, Theil-Sen.

5. Optimization

Explain gradient descent.

Iteratively update parameters opposite to the gradient of the loss: θ ← θ − η∇L(θ). Learning rate η too small → slow; too large → divergence/oscillation.

Batch vs stochastic vs mini-batch gradient descent?

Batch GD: full dataset per step; stable, slow, memory heavy. SGD: one sample per step; noisy, fast updates, noise can escape saddle points/sharp minima. Mini-batch (32–1024): compromise; uses GPU parallelism efficiently; the standard in deep learning.

What is momentum? Nesterov momentum?

Momentum accumulates an exponentially decaying average of past gradients: v = βv + ∇L; θ -= ηv. It accelerates along consistent directions and dampens oscillations in ravines. Nesterov evaluates the gradient at the look-ahead position (θ − ηβv), giving more responsive corrections.

Explain AdaGrad, RMSProp and Adam.

  • AdaGrad: per-parameter learning rates scaled by the sum of squared past gradients; good for sparse features but learning rate decays to near zero.
  • RMSProp: uses an exponential moving average of squared gradients instead of the sum, fixing AdaGrad's decay.
  • Adam: momentum (1st moment m) + RMSProp (2nd moment v) with bias correction: θ -= η·m̂/(√v̂ + ε). Defaults β1=0.9, β2=0.999. Fast and robust; sometimes generalizes slightly worse than SGD+momentum.

What is AdamW and why is it preferred?

In Adam, L2 regularization added to the loss gets scaled by the adaptive denominator, so it is not true weight decay. AdamW decouples weight decay, applying it directly to weights (θ -= ηλθ). It generalizes better and is the default for Transformers.

What are learning rate schedules?

Step decay, exponential decay, cosine annealing, cosine with warm restarts (SGDR), one-cycle policy, reduce-on-plateau, linear warmup then decay (standard for Transformers since early large updates with Adam's unstable statistics can diverge).

How do you choose a good learning rate?

Start from common defaults (Adam: 1e-3 or 3e-4; SGD with momentum: ~0.1 for CNNs), then tune on a log scale. Use an LR range test: increase the LR exponentially over a few hundred steps and pick a value about 10× below where the loss starts to blow up. Read loss curves: diverging or oscillating means too high; very slow decrease means too low. Combine with warmup and decay schedules.

What are saddle points and local minima? Which is the bigger problem in deep learning?

In high dimensions, saddle points (gradient zero, curvature positive in some directions and negative in others) are far more common than bad local minima. Most local minima of large networks have similar loss. Momentum and SGD noise help escape saddle points and plateaus.

What are second-order optimization methods? Why are they rarely used in deep learning?

Newton's method uses the Hessian: θ -= H−1∇L; converges in fewer steps. Quasi-Newton methods (BFGS, L-BFGS) approximate the Hessian. For networks with millions of parameters, storing/inverting a d×d Hessian is infeasible, and stochastic mini-batches make curvature estimates noisy.

How does batch size affect training?

Larger batches: more accurate gradients, better hardware utilization, fewer steps, but may converge to sharper minima and generalize worse and need learning-rate scaling (linear scaling rule with warmup). Smaller batches: noisier gradients acting as regularization, more updates, slower per epoch. Memory limits batch size; gradient accumulation simulates larger batches.

What is gradient clipping?

Limiting gradient magnitude (by value or by global norm) before the update to prevent exploding gradients, especially in RNNs and Transformers.

What is early stopping?

Monitor validation loss and stop when it hasn't improved for a "patience" number of epochs, restoring the best weights. Acts as regularization, similar in effect to L2 for linear models.

What is the difference between an epoch, a batch and an iteration?

Epoch: one full pass over the training data. Batch: subset of samples used in one update. Iteration: one parameter update. Iterations per epoch = dataset size / batch size.

6. Decision Trees & Ensembles

How does a decision tree work?

Recursively splits data on the feature/threshold that best improves purity (classification) or reduces variance (regression), forming a tree of if-else rules. Leaves predict the majority class or mean value. Greedy, top-down (CART, ID3, C4.5).

Gini impurity vs entropy (information gain)?

Gini = 1 − Σpk²; Entropy = −Σpk log pk. Information gain = parent entropy − weighted child entropy. Both give similar trees; Gini is slightly faster (no log). Information gain is biased toward high-cardinality features; C4.5 uses gain ratio to correct this. Regression trees use MSE/variance reduction.

How do you prevent overfitting in decision trees?

Pre-pruning: max_depth, min_samples_split, min_samples_leaf, max_leaf_nodes, min_impurity_decrease. Post-pruning: cost-complexity pruning (ccp_alpha). Or use ensembles (random forest, boosting).

Advantages and disadvantages of decision trees?

Pros: interpretable, handle non-linearity and interactions, no scaling needed, handle mixed types, fast inference. Cons: high variance/unstable, overfit easily, axis-aligned splits, poor extrapolation, greedy (not globally optimal), biased toward dominant classes.

What is bagging?

Bootstrap Aggregating: train models on bootstrap samples in parallel and average (regression) or vote (classification). Reduces variance; best with high-variance, low-bias base learners like deep trees.

How does random forest work and why is it better than bagged trees?

Bagging of decision trees plus random feature subsampling at each split (typically √d for classification, d/3 for regression). The feature randomness decorrelates trees, so averaging reduces variance more. Robust, little tuning, gives feature importance and OOB error.

What is out-of-bag (OOB) error?

Each tree leaves out ~36.8% of samples. Predicting each sample using only trees that didn't see it gives an OOB estimate of generalization error, a free validation score without a separate holdout.

What is boosting? How does it differ from bagging?

Boosting trains weak learners sequentially, each focusing on errors of the previous ensemble, and combines them in a weighted sum. Reduces bias (and variance). Bagging is parallel, independent models, reduces variance. Boosting is more prone to overfitting noise and needs careful tuning (learning rate, n_estimators, depth).

Explain AdaBoost.

Start with equal sample weights; train a weak learner (often a stump); compute weighted error ε and learner weight α = ½ ln((1−ε)/ε); increase weights of misclassified samples; repeat. Final prediction: sign(Σαtht(x)). Equivalent to minimizing exponential loss; sensitive to outliers.

Explain gradient boosting.

Builds an additive model Fm(x) = Fm−1(x) + η·hm(x), where each new tree hm fits the negative gradient of the loss w.r.t. current predictions (pseudo-residuals; for MSE these are ordinary residuals). It's gradient descent in function space and works with any differentiable loss. Key hyperparameters: learning rate, n_estimators, max_depth, subsample, min_child_weight.

What makes XGBoost better than vanilla gradient boosting?

Second-order Taylor approximation of the loss (gradient + Hessian), regularized objective (L1/L2 on leaf weights, γ penalty on number of leaves), sparsity-aware split finding (learns default direction for missing values), weighted quantile sketch for approximate splits, column/row subsampling, parallelized split finding, cache-aware and out-of-core computation, built-in CV and early stopping.

How does XGBoost compute leaf weights and split gain?

Using a second-order Taylor expansion, each sample has gradient gi and Hessian hi. For a leaf with sums G = Σgi and H = Σhi, the optimal weight is w* = −G / (H + λ). The gain of splitting a node into left and right children is:
Gain = ½[GL²/(HL+λ) + GR²/(HR+λ) − (GL+GR)²/(HL+HR+λ)] − γ
A split is kept only if the gain is positive, so γ acts as built-in pruning and λ shrinks leaf weights. min_child_weight sets a minimum H per leaf.

XGBoost vs LightGBM vs CatBoost?

XGBoostLightGBMCatBoost
Level-wise growth; histogram or exact splits; very mature. Leaf-wise (best-first) growth: faster, lower loss, but can overfit small data (limit num_leaves). Histogram binning, GOSS (gradient-based one-side sampling), EFB (exclusive feature bundling). Fastest on large data. Symmetric (oblivious) trees; native categorical handling with ordered target statistics; ordered boosting to reduce prediction shift/target leakage; strong defaults.

How is feature importance computed in tree models? What are its pitfalls?

Impurity-based (mean decrease in Gini/variance), split count, gain. Pitfalls: biased toward high-cardinality/continuous features, computed on training data, unreliable with correlated features. Better: permutation importance on validation data, or SHAP values (TreeSHAP).

What are stacking, blending and voting?

Voting: combine predictions by majority (hard) or averaged probabilities (soft). Stacking: train a meta-model on out-of-fold predictions of base models. Blending: like stacking but the meta-model is trained on predictions on a holdout set. Works best with diverse base models.

Why do ensembles work?

If base models are accurate and make uncorrelated errors, averaging cancels individual errors, reducing variance (and boosting reduces bias). Variance of an average of n models with correlation ρ is ρσ² + (1−ρ)σ²/n, so lowering correlation is key.

Can tree-based models extrapolate?

No. Predictions are constants (averages) in leaves, so outside the training range they stay flat at boundary values. For trends (e.g., time series growth), detrend first or use linear models.

Why do gradient boosted trees often beat deep learning on tabular data?

Tabular data has heterogeneous, non-smooth, often irregular features and moderate sample sizes; trees handle irregular decision boundaries, uninformative features, missing values, and different scales without preprocessing, and are easier to tune.

7. SVM, KNN & Naive Bayes

Explain Support Vector Machines.

SVM finds the hyperplane that maximizes the margin between classes. The closest points (support vectors) define it. Hard margin requires separability; soft margin allows violations via slack variables controlled by C. Objective: min ½||w||² + CΣξi, equivalently hinge loss max(0, 1 − y·f(x)) + L2 regularization.

What is the effect of the C parameter in SVM?

Large C: penalizes misclassification heavily → narrow margin, low bias, high variance. Small C: wider margin, more violations allowed → more regularization.

What is the kernel trick?

Kernels compute inner products in a high-dimensional feature space without explicitly mapping data: K(x, z) = φ(x)·φ(z). Since the SVM dual depends only on inner products, it can learn non-linear boundaries efficiently. Kernels: linear, polynomial (x·z + c)d, RBF/Gaussian exp(−γ||x−z||²), sigmoid. Valid kernels must be positive semi-definite (Mercer's theorem).

What does gamma do in the RBF kernel?

Controls the reach of each support vector. High γ: very local influence, wiggly boundary, overfitting. Low γ: smoother boundary, may underfit. Tune C and γ together.

SVM pros and cons? Does SVM output probabilities?

Pros: effective in high dimensions, memory efficient (support vectors), strong with clear margin, flexible kernels. Cons: O(n²)–O(n³) training (poor for large n), sensitive to scaling and hyperparameters, less interpretable. SVM outputs distances, not probabilities; use Platt scaling for calibrated probabilities. SVR is the regression version with an ε-insensitive tube.

How does KNN work and how do you choose k?

Lazy, instance-based: predict by majority vote (classification) or average (regression) of the k nearest training points. Small k: low bias, high variance, noisy. Large k: smoother, more bias. Choose k via CV; use odd k for binary classification. Use distance weighting optionally.

What distance metrics are used in ML?

Euclidean (L2), Manhattan (L1), Minkowski (generalization), Chebyshev (L∞), cosine (orientation; text/embeddings), Hamming (categorical/binary), Jaccard (sets), Mahalanobis (accounts for covariance).

KNN drawbacks and speedups?

Slow prediction O(n·d) per query, memory heavy, needs scaling, suffers from curse of dimensionality, sensitive to irrelevant features and imbalance. Speedups: KD-trees, Ball trees, approximate nearest neighbor (HNSW, FAISS, LSH).

How does Naive Bayes work? Why "naive"?

Applies Bayes' theorem assuming features are conditionally independent given the class: P(y|x) ∝ P(y)ΠP(xi|y). "Naive" because independence rarely holds, but it still classifies well (ranking is often correct even if probabilities are poorly calibrated). Variants: Gaussian (continuous), Multinomial (counts, text), Bernoulli (binary features), Complement NB (imbalanced text).

What is Laplace smoothing?

Adding a pseudo-count (α, typically 1) to every feature count so unseen feature-class combinations don't get zero probability, which would zero out the whole product.

Why compute Naive Bayes in log space?

Multiplying many small probabilities underflows to zero; summing log probabilities is numerically stable.

8. Unsupervised Learning & Dimensionality Reduction

Explain k-means clustering.

Initialize k centroids; assign each point to its nearest centroid; recompute centroids as cluster means; repeat until convergence. Minimizes within-cluster sum of squares (inertia). Converges to a local optimum; complexity O(n·k·d·iterations).

What is k-means++?

Smart initialization: choose the first centroid randomly, then pick subsequent centroids with probability proportional to squared distance from the nearest chosen centroid. Spreads centroids out, faster convergence and better results.

How do you choose k in k-means?

Elbow method (inertia vs k), silhouette score (higher is better, range −1 to 1), gap statistic, Davies-Bouldin index (lower better), Calinski-Harabasz (higher better), and domain knowledge/business use.

Limitations of k-means?

Must choose k; assumes spherical, similarly sized clusters; sensitive to initialization, outliers and scaling; only numeric data (use k-modes/k-prototypes for categorical); struggles with non-convex shapes.

K-means vs KNN?

K-means: unsupervised clustering; k = number of clusters; iteratively learns centroids. KNN: supervised classification/regression; k = number of neighbors; lazy learner with no training phase. Both rely on distance metrics and need feature scaling.

Explain hierarchical clustering.

Agglomerative (bottom-up): start with each point as a cluster and repeatedly merge the closest pair; divisive is top-down. Linkage: single (min distance; chaining), complete (max), average, Ward (minimizes variance increase). Produces a dendrogram; cut at a height to get clusters. O(n²) memory, no need to pre-specify k.

Explain DBSCAN.

Density-based: points with at least minPts neighbors within ε are core points; clusters grow from core points through density-reachable points; others are noise. Finds arbitrary shapes, detects outliers, no k needed. Struggles with varying densities (use HDBSCAN) and high dimensions; sensitive to ε.

What are Gaussian Mixture Models and the EM algorithm?

GMM models data as a mixture of K Gaussians with soft (probabilistic) assignments and elliptical clusters. Fit with Expectation-Maximization: E-step computes responsibilities (posterior cluster probabilities) given current parameters; M-step updates means, covariances, and mixing weights to maximize expected log-likelihood. K-means is a special case (hard assignments, equal spherical covariance). Choose K with BIC/AIC.

Explain PCA.

Linear dimensionality reduction that projects data onto orthogonal directions (principal components) of maximum variance. Steps: standardize, compute covariance matrix, eigen-decompose (or SVD of centered data), sort eigenvectors by eigenvalue, project onto top k. Choose k by explained variance (e.g., 95%) or scree plot. Limitations: linear, sensitive to scaling, components less interpretable, variance ≠ predictive relevance.

How are PCA and SVD related?

For centered data X = UΣVT, the columns of V are the principal directions, and eigenvalues of the covariance are σi²/(n−1). SVD is more numerically stable than forming the covariance matrix.

PCA vs LDA (Linear Discriminant Analysis)?

PCA is unsupervised and maximizes variance. LDA is supervised and maximizes between-class separation relative to within-class scatter; at most (C−1) components. LDA is also a classifier assuming Gaussian classes with shared covariance.

t-SNE vs UMAP?

Both are non-linear methods for visualization. t-SNE matches neighbor probability distributions (Gaussian in high-D, Student-t in low-D to avoid crowding); preserves local structure, slow, stochastic, perplexity-sensitive; cluster sizes/distances are not meaningful; no transform for new data. UMAP: based on manifold theory and fuzzy topological graphs; faster, scales better, preserves more global structure, supports transforming new points.

What other dimensionality reduction methods exist?

Kernel PCA (non-linear), ICA (statistically independent sources; blind source separation), NMF (non-negative parts-based; topic modeling), truncated SVD/LSA (sparse text), autoencoders, feature selection, random projections (Johnson-Lindenstrauss).

What anomaly detection methods do you know?

Statistical (z-score, IQR, Gaussian density), Isolation Forest (anomalies are isolated in fewer random splits → shorter path length), Local Outlier Factor (local density compared to neighbors), One-Class SVM, DBSCAN noise points, autoencoder reconstruction error, and forecasting residuals for time series.

What is association rule mining?

Finding item co-occurrence rules X → Y in transactions (market basket). Metrics: support = P(X∪Y), confidence = P(Y|X), lift = confidence / P(Y) (>1 means positive association). Algorithms: Apriori (prunes using frequent-subset property), FP-Growth (prefix tree, no candidate generation).

How do you evaluate clustering without labels?

Internal metrics: silhouette, Davies-Bouldin, Calinski-Harabasz, inertia. With ground truth: Adjusted Rand Index, Normalized Mutual Information, homogeneity/completeness. Also stability across resamples and business usefulness.

What is topic modeling (LDA - Latent Dirichlet Allocation)?

Generative model where each document is a mixture of topics and each topic is a distribution over words, with Dirichlet priors. Inferred via Gibbs sampling or variational inference. Evaluate with coherence scores. Modern alternative: BERTopic (embeddings + clustering + c-TF-IDF).

Explain the confusion matrix and derived metrics.

Accuracy = (TP+TN)/All. Precision = TP/(TP+FP). Recall/Sensitivity/TPR = TP/(TP+FN). Specificity/TNR = TN/(TN+FP). FPR = FP/(FP+TN). F1 = 2PR/(P+R).

When to prioritize precision vs recall?

Precision when false positives are costly: spam filtering (don't lose real emails), recommending content, legal decisions. Recall when false negatives are costly: cancer screening, fraud detection, safety defects. Fβ balances them (β > 1 weights recall).

Why does the F1 score use the harmonic mean instead of the arithmetic mean?

The harmonic mean is dominated by the smaller value, so F1 is high only when both precision and recall are high. A model with precision 1.0 and recall 0.0 would get 0.5 with the arithmetic mean but 0 with F1.

Why is accuracy misleading on imbalanced data?

With 99% negatives, predicting all negative gives 99% accuracy but zero recall. Use precision, recall, F1, PR-AUC, balanced accuracy, MCC (Matthews correlation coefficient), or Cohen's kappa.

Explain ROC curve and AUC.

ROC plots TPR vs FPR across all thresholds. AUC is the probability that a random positive is scored higher than a random negative; 0.5 = random, 1.0 = perfect. Threshold-independent and scale-invariant; measures ranking quality.

ROC-AUC vs PR-AUC?

With heavy imbalance, FPR stays small because TN is huge, so ROC-AUC can look optimistic. PR curves (precision vs recall) focus on the positive class and are more informative for rare positives; baseline PR-AUC equals positive prevalence.

How do you choose a classification threshold?

Based on business costs: maximize F1/Fβ, use Youden's J (TPR − FPR) on ROC, set a minimum precision or recall constraint, or minimize expected cost (costFP·FP + costFN·FN). Choose on validation data, not test.

Micro vs macro vs weighted averaging in multi-class metrics?

Macro: compute metric per class, average equally (treats rare classes equally). Micro: aggregate TP/FP/FN globally (dominated by frequent classes; micro-F1 = accuracy in single-label multi-class). Weighted: macro weighted by class support.

Explain regression metrics.

  • MAE: mean |error|; robust to outliers; median-optimal.
  • MSE: mean squared error; penalizes large errors; mean-optimal; differentiable.
  • RMSE: √MSE; same units as target.
  • R² / adjusted R²: variance explained.
  • MAPE: mean |error/actual|; scale-free but undefined at zero and asymmetric; sMAPE fixes partly.
  • RMSLE: penalizes under-prediction more; for targets spanning orders of magnitude.
  • Huber: MSE for small errors, MAE for large.

What is log loss and why use it?

−(1/N)Σ[y log p + (1−y) log(1−p)]. Evaluates the quality of predicted probabilities, heavily penalizing confident wrong predictions. Useful when calibrated probabilities matter.

What is model calibration and how do you calibrate?

A model is calibrated if, among predictions with probability 0.8, about 80% are positive. Check with reliability diagrams, Brier score, Expected Calibration Error (ECE). Calibrate with Platt scaling (logistic fit on scores), isotonic regression, or temperature scaling (neural nets). Boosted trees, SVMs, Naive Bayes, and deep nets are often miscalibrated.

How do you quantify uncertainty in predictions? What is conformal prediction?

Aleatoric uncertainty comes from noise in the data (irreducible); epistemic uncertainty comes from limited knowledge (reducible with more data). Methods: calibrated probabilities, prediction intervals via quantile regression, ensembles (spread of predictions), MC dropout, Bayesian models. Conformal prediction uses a held-out calibration set of residuals/non-conformity scores to turn any model's output into prediction intervals (regression) or prediction sets (classification) with a guaranteed coverage such as 90%, assuming exchangeable data.

What are ranking metrics?

Precision@k / Recall@k; MAP (mean average precision over queries); MRR (mean of 1/rank of first relevant item); NDCG@k (discounted cumulative gain with graded relevance, normalized by ideal ordering); hit rate; coverage and diversity for recommenders.

What are learning curves and validation curves?

Learning curves plot train/validation score vs training set size: a large gap means high variance (more data helps); both low and close means high bias. Validation curves plot scores vs a hyperparameter value to find the sweet spot between under- and overfitting.

How do you compare two models statistically?

Use the same CV folds and a paired test: paired t-test on fold scores (corrected resampled t-test), McNemar's test on classification disagreements, 5×2 CV test, or bootstrap confidence intervals of the metric difference.

What metrics are used for object detection, segmentation and NLP generation?

Detection: IoU, mAP@0.5, mAP@[0.5:0.95]. Segmentation: pixel accuracy, mean IoU, Dice coefficient. Generation: BLEU (n-gram precision, translation), ROUGE (recall, summarization), METEOR, BERTScore, perplexity, human/LLM-as-judge evaluation.

How do you explain a model's predictions (feature importance, SHAP, LIME)?

Global explanations describe overall behavior: coefficients (linear models), permutation importance (drop in validation score when a feature is shuffled), partial dependence plots. Local explanations describe one prediction: SHAP assigns each feature its Shapley value (average marginal contribution across feature combinations; contributions sum to prediction minus baseline; TreeSHAP is fast for tree models); LIME fits a simple surrogate model on perturbed samples around the instance. Needed for trust, debugging, leakage detection and regulatory compliance.

10. Model Selection & Hyperparameter Tuning

Grid search vs random search vs Bayesian optimization?

Grid search: exhaustive over a grid; expensive, scales exponentially. Random search: samples combinations; more efficient since few hyperparameters usually matter (Bergstra & Bengio). Bayesian optimization: builds a surrogate model (Gaussian process, TPE) of score vs hyperparameters and picks the next trial using an acquisition function (Expected Improvement, UCB), balancing exploration/exploitation. Tools: Optuna, Hyperopt, Ray Tune.

What are AIC and BIC?

Model selection criteria balancing fit and complexity: AIC = 2k − 2 ln L; BIC = k ln n − 2 ln L. Lower is better; BIC penalizes complexity more and prefers simpler models for large n.

What is Occam's razor in ML?

Among models with similar performance, prefer the simpler one: it generalizes better, is easier to interpret, maintain and serve.

Which hyperparameters matter most for common models?

Random forest: n_estimators, max_features, max_depth, min_samples_leaf. GBM/XGBoost: learning_rate, n_estimators (with early stopping), max_depth/num_leaves, subsample, colsample_bytree, min_child_weight, regularization. SVM: C, kernel, γ. Neural nets: learning rate (most important), batch size, architecture size, weight decay, dropout, optimizer, schedule.

11. Time Series

What are the components of a time series?

Trend (long-term direction), seasonality (fixed-period patterns), cyclical (non-fixed longer cycles), and residual/noise. Decompose additively (y = T + S + R) or multiplicatively (y = T × S × R), e.g., STL decomposition.

What is stationarity and how do you test/achieve it?

A stationary series has constant mean, variance and autocovariance over time. Tests: Augmented Dickey-Fuller (H0: non-stationary/unit root), KPSS (H0: stationary). Achieve via differencing, seasonal differencing, log/Box-Cox transforms, detrending.

Explain ACF and PACF.

ACF: correlation of the series with its lags (including indirect effects). PACF: correlation with a lag after removing effects of shorter lags. For AR(p), PACF cuts off after p; for MA(q), ACF cuts off after q.

Explain ARIMA and SARIMA.

ARIMA(p, d, q): AutoRegressive terms (p past values), Integrated (d differences), Moving Average (q past errors). SARIMA adds seasonal (P, D, Q, s) terms; ARIMAX/SARIMAX adds exogenous variables. Select orders via ACF/PACF, AIC, or auto-ARIMA.

What other forecasting methods exist?

Naive / seasonal naive baselines, moving averages, exponential smoothing (Holt-Winters: level, trend, seasonality), Prophet (trend + seasonality + holidays), VAR (multivariate), gradient boosting with lag/rolling features, RNN/LSTM, Temporal Convolutional Networks, Transformers (Temporal Fusion Transformer, Informer, PatchTST), N-BEATS, foundation models (TimeGPT, Chronos).

How do you validate time series models?

Never shuffle. Use walk-forward / expanding or sliding window validation (TimeSeriesSplit), with a gap between train and test if features use lags. Compute features only from past data. Metrics: MAE, RMSE, MAPE, sMAPE, MASE (scaled by naive forecast).

How do you convert a time series into a supervised learning problem?

Create lag features (yt−1, yt−7), rolling statistics (mean, std over windows, shifted to avoid leakage), date features (day, month, holiday), and exogenous variables. For multi-step forecasting: recursive (feed predictions back), direct (one model per horizon), or multi-output.

12. Recommender Systems

What are the main types of recommender systems?

Content-based: recommend items similar to those the user liked using item features. Collaborative filtering: use user-item interactions; user-based (similar users) or item-based (similar items). Hybrid: combine both. Knowledge-based and popularity-based baselines.

Explain matrix factorization for recommendations.

Approximate the sparse user-item rating matrix R ≈ U·VT with low-dimensional latent factors for users and items, learned by minimizing squared error on observed entries plus regularization, via SGD or Alternating Least Squares (ALS). Predicted rating = ui·vj + biases. Popularized by the Netflix Prize (SVD++, etc.).

Explicit vs implicit feedback?

Explicit: ratings, likes (sparse, biased). Implicit: clicks, views, purchases, watch time (abundant, noisy, no negatives). Implicit needs negative sampling and losses like BPR (Bayesian Personalized Ranking) or weighted ALS.

What is the cold-start problem and how to address it?

New users or items lack interaction history. Solutions: content-based features, popularity/trending recommendations, onboarding questionnaires, demographic/contextual features, hybrid models, exploration via bandits, and using metadata embeddings.

Describe a modern large-scale recommender architecture.

Multi-stage: candidate generation (two-tower models producing user and item embeddings, retrieved via approximate nearest neighbor search) → ranking (heavier model such as Wide & Deep, DeepFM, DCN, DLRM, or GBDT with rich features predicting click/engagement) → re-ranking (diversity, freshness, business rules, fairness). Evaluate offline (NDCG, recall@k) and online (A/B: CTR, retention).

What is learning to rank? Pointwise vs pairwise vs listwise?

Training models to order items by relevance for a query or user. Pointwise: predict a relevance score/label per item (regression/classification). Pairwise: learn to order pairs correctly (RankNet, RankSVM). Listwise: optimize a metric over the whole list such as NDCG (ListNet, LambdaRank). LambdaMART (gradient boosted trees with lambda gradients; rank:ndcg in XGBoost, lambdarank in LightGBM) is a strong industry standard. Click data needs position-bias correction.

What are multi-armed bandits?

Online methods balancing exploration and exploitation: ε-greedy, Upper Confidence Bound (UCB), Thompson sampling. Contextual bandits (LinUCB) use features. Used for recommendations, ad selection and adaptive A/B testing.

13. Deep Learning Fundamentals

What is deep learning and why has it succeeded recently?

Deep learning uses neural networks with many layers to learn hierarchical representations directly from raw data, removing manual feature engineering. Success drivers: large datasets, GPUs/TPUs, better architectures (ResNets, Transformers), better training techniques (ReLU, BatchNorm, Adam, residual connections), and open-source frameworks.

Explain the structure of a neural network. What are weights and biases?

An input layer, one or more hidden layers, and an output layer. Each neuron computes a weighted sum of its inputs plus a bias and applies an activation: a = f(w·x + b). Weights set the strength of each connection; the bias shifts the activation threshold so the decision boundary need not pass through the origin. In dense (fully connected) layers every neuron connects to all neurons of the previous layer. Training adjusts weights and biases via backpropagation.

What is a tensor? Why are GPUs used for deep learning?

A tensor is an n-dimensional array: scalar (0-D), vector (1-D), matrix (2-D), and higher, e.g., a batch of images has shape (N, C, H, W). Deep learning is dominated by large matrix multiplications and convolutions that are highly parallel; GPUs have thousands of cores and high memory bandwidth to do these in parallel, often 10–100× faster than CPUs. TPUs and NPUs are chips specialized for the same operations.

What is a perceptron? Why can't it solve XOR?

A single neuron computing step(w·x + b); a linear classifier. XOR is not linearly separable, so one perceptron can't solve it. A multi-layer perceptron with a hidden layer and non-linear activation can.

What is the Universal Approximation Theorem?

A feed-forward network with a single hidden layer of enough neurons and a non-linear activation can approximate any continuous function on a compact domain to arbitrary accuracy. It says nothing about how many neurons are needed, or whether training can find the weights; deep networks represent many functions far more efficiently than wide shallow ones.

Why do we need non-linear activation functions?

Without them, stacked linear layers collapse into a single linear transformation (W2W1x = Wx), so depth adds no expressive power.

What is the dying ReLU problem?

If a neuron's pre-activation is negative for all inputs (e.g., due to a large learning rate or bad bias), its gradient is zero and it never updates again. Fix with Leaky ReLU/ELU/GELU, proper initialization, and lower learning rates.

Which activation should be used in the output layer (sigmoid vs softmax vs linear)?

  • Binary classification: 1 sigmoid unit + binary cross-entropy.
  • Multi-class (one label per sample): softmax over K units + categorical cross-entropy; probabilities sum to 1.
  • Multi-label (several labels per sample): K independent sigmoid units + binary cross-entropy per label.
  • Regression: linear (no activation); ReLU/softplus if output must be non-negative.

Hidden layers typically use ReLU/GELU, not sigmoid.

Explain forward propagation and backpropagation.

Forward: compute layer outputs sequentially to get predictions and loss. Backward: apply the chain rule from the loss back through each layer to compute gradients of the loss w.r.t. every parameter, reusing intermediate results (reverse-mode automatic differentiation), then update weights with an optimizer. Cost of backward pass is about 2× forward.

Derive the gradient of softmax + cross-entropy.

For logits z, p = softmax(z), and one-hot target y, L = −Σyk log pk. Then ∂L/∂zk = pk − yk. This simple, well-behaved gradient is why softmax and cross-entropy are combined (also numerically stable via log-sum-exp). Similarly, sigmoid + BCE gives p − y.

What is automatic differentiation? Static vs dynamic computation graphs?

Autodiff computes exact derivatives by recording elementary operations in a computational graph and applying the chain rule (reverse mode for many-inputs-to-scalar-loss). Dynamic graphs (PyTorch eager) are built on the fly, easy to debug, support Python control flow. Static graphs (TF1, compiled modes like torch.compile, JAX jit, XLA) allow global optimizations.

What are vanishing and exploding gradients? How to address them?

During backprop, gradients are products of many layer Jacobians; if factors are <1 they shrink exponentially (early layers stop learning), if >1 they explode (unstable training, NaNs). Remedies: ReLU-family activations, proper initialization (Xavier/He), batch/layer normalization, residual connections, LSTM/GRU gating, gradient clipping, smaller learning rates.

Why does weight initialization matter? Explain Xavier and He initialization.

All-zero initialization makes neurons symmetric (they learn the same thing). Too large/small weights cause exploding/vanishing activations. Xavier/Glorot: Var(w) = 2/(fan_in + fan_out), designed for tanh/sigmoid. He/Kaiming: Var(w) = 2/fan_in, designed for ReLU (which zeroes half the inputs). Both keep activation variance roughly constant across layers.

Which loss functions are used for which tasks?

  • Regression: MSE, MAE, Huber, log-cosh, quantile (pinball) loss.
  • Binary classification: binary cross-entropy (BCEWithLogits), hinge.
  • Multi-class: categorical cross-entropy; multi-label: per-label sigmoid BCE.
  • Imbalanced/detection: focal loss = −α(1−p)γ log p (down-weights easy examples).
  • Segmentation: Dice loss, IoU/Jaccard loss, combined with CE.
  • Metric learning: contrastive loss, triplet loss (anchor-positive closer than anchor-negative by margin), InfoNCE.
  • Distributions: KL divergence; GANs: adversarial loss; ranking: pairwise/listwise losses.

What is the difference between a logit, a probability and log-odds?

Logits are raw unnormalized scores output by the last layer. Softmax/sigmoid convert logits into probabilities. For binary sigmoid output, the logit equals log-odds log(p/(1−p)). Losses like CrossEntropyLoss take logits for numerical stability.

What are the differences between ML and DL?

Classical ML relies on hand-engineered features and works well on small/structured data with fast training and better interpretability. DL learns features automatically, excels on unstructured data (images, text, audio) with lots of data and compute, but is less interpretable and more resource intensive.

How do you count parameters in dense and convolutional layers?

Dense: (inputs × outputs) + outputs (bias). Conv2D: (kh × kw × Cin + 1) × Cout. Example: 3×3 conv, 64→128 channels = (3·3·64 + 1)·128 = 73,856.

How do you choose the number of hidden layers and neurons?

There is no formula. Start from a proven architecture for the data type, or a small network (1–3 hidden layers) for tabular data. Increase capacity until training error is low and validation stops improving, then control overfitting with regularization; a slightly larger network with dropout/weight decay usually beats a too-small one. Tune with random or Bayesian search and prefer transfer learning when possible.

What is an autoencoder and what is it used for?

A network with an encoder that compresses the input into a low-dimensional latent code (bottleneck) and a decoder that reconstructs the input; trained to minimize reconstruction loss without labels. Uses: non-linear dimensionality reduction, denoising (denoising autoencoder), anomaly detection (high reconstruction error flags anomalies), feature learning and pretraining. Unlike PCA, it can learn non-linear structure.

When would you use an MLP vs CNN vs RNN vs Transformer?

  • MLP: fixed-size feature vectors / tabular data (though gradient boosting often wins there).
  • CNN: grid-like data with local patterns: images, spectrograms, 1D signals.
  • RNN/LSTM/GRU: sequential data with small datasets, streaming or low-latency step-by-step processing, some time series.
  • Transformer: text and sequences with long-range dependencies and large data; ViT for images with lots of data.

14. Training Deep Networks & Regularization

How do you prevent overfitting in neural networks?

Get more data or use data augmentation; use transfer learning; add regularization (weight decay/L2, dropout, label smoothing); use batch normalization; apply early stopping on validation loss; reduce model size; use ensembles; and make sure train/validation splits are clean (no leakage or duplicates).

Explain batch normalization. Why does it help?

Normalizes each feature over the mini-batch to zero mean and unit variance, then applies learnable scale γ and shift β. Uses running averages at inference. Benefits: allows higher learning rates, faster convergence, less sensitivity to initialization, mild regularization. Originally attributed to reducing "internal covariate shift"; later work suggests it mainly smooths the loss landscape. Downsides: depends on batch size, differs between train/eval, awkward for RNNs and small batches.

Batch norm vs layer norm vs instance norm vs group norm?

BatchNorm: normalize across batch per channel (CNNs, large batches). LayerNorm: normalize across features per sample, batch-independent (Transformers, RNNs). InstanceNorm: per sample per channel (style transfer). GroupNorm: per sample over groups of channels (small-batch detection/segmentation). RMSNorm: LayerNorm without mean-centering (LLaMA), cheaper.

How does dropout work? Why does it regularize?

During training, randomly zero each activation with probability p and scale survivors by 1/(1−p) (inverted dropout) so inference needs no change. It prevents co-adaptation of neurons and approximates averaging an exponential ensemble of sub-networks. Disabled at inference (model.eval()). MC Dropout keeps it on at inference to estimate uncertainty.

L2 regularization vs weight decay?

For plain SGD they are equivalent. For adaptive optimizers like Adam they differ, because L2's gradient is rescaled per parameter; decoupled weight decay (AdamW) applies shrinkage directly and works better.

What is label smoothing?

Replace one-hot targets with (1−ε) for the true class and ε/(K−1) (or ε/K) for others. Prevents over-confident logits, improves calibration and generalization (used in Inception, Transformers).

What are residual (skip) connections and why do they work?

Output = F(x) + x. The layer learns a residual, so learning identity is easy; gradients flow directly through the identity path, mitigating vanishing gradients and the degradation problem, enabling 100+ layer networks (ResNet) and deep Transformers.

Describe a typical training loop (e.g., in PyTorch).

  1. For each epoch, call model.train() and iterate over mini-batches from a DataLoader.
  2. Move data to the device; forward pass to get outputs; compute loss.
  3. optimizer.zero_grad() (gradients accumulate otherwise), loss.backward(), optionally clip gradients, optimizer.step(), step the LR scheduler.
  4. Validation: model.eval() (disables dropout, uses BatchNorm running stats) inside torch.no_grad() (no gradient tracking, saves memory); compute metrics.
  5. Log metrics, checkpoint the best model, apply early stopping.

PyTorch vs TensorFlow/Keras?

PyTorch: Pythonic, eager (dynamic graphs), easy debugging, dominant in research and increasingly in production (TorchScript, torch.compile, ONNX). TensorFlow/Keras: high-level Keras API for quick model building, mature production ecosystem (TF Serving, TF Lite for mobile, TF.js), graph compilation with tf.function. Both support GPUs/TPUs and distributed training; the choice is often driven by team and deployment ecosystem.

What are the steps to debug a neural network that isn't learning?

  1. Overfit a tiny batch first; if it can't reach ~0 loss, there's a bug.
  2. Check data pipeline: labels aligned, normalization, augmentation correctness, shuffling.
  3. Check loss/activation pairing (logits vs probabilities), loss scale at init (~ln K for K classes).
  4. Tune learning rate (LR range test); check for NaNs, exploding/vanishing gradients (monitor gradient norms).
  5. Verify model.train()/eval(), zeroing gradients, correct optimizer params.
  6. Simplify architecture; then add complexity back.

What is mixed-precision training?

Use FP16/BF16 for most computations and FP32 master weights for updates. Speeds up training on Tensor Cores and halves memory. FP16 needs loss scaling to avoid gradient underflow; BF16 has FP32's exponent range so usually doesn't.

What is gradient accumulation and gradient checkpointing?

Gradient accumulation: sum gradients over several small batches before an update to emulate a large batch under memory limits. Gradient (activation) checkpointing: store only some activations during forward and recompute the rest during backward, trading compute for memory.

How is deep learning training distributed across devices?

Data parallelism (DDP): replicate model, split batches, all-reduce gradients. ZeRO / FSDP: shard optimizer states, gradients and parameters across devices. Tensor parallelism: split individual layers' matrices. Pipeline parallelism: split layers across devices with micro-batches. Large LLMs combine all (3D parallelism).

What is knowledge distillation?

A small student model is trained to match the softened output distribution (soft targets, temperature T) of a large teacher, plus the true labels. Soft targets carry "dark knowledge" about class similarities. Used to compress models (DistilBERT, TinyLLMs).

15. Convolutional Neural Networks & Computer Vision

Why use CNNs instead of fully connected networks for images?

Local connectivity (neurons see local patches), weight sharing (same filter across positions → far fewer parameters), and translation equivariance (features detected anywhere). Pooling adds some translation invariance. Hierarchy: edges → textures → parts → objects.

How does a convolution operation work? What is a feature map?

A small learnable filter (kernel, e.g., 3×3×Cin) slides over the input; at each position it computes the sum of element-wise products plus a bias, producing one value of the output feature map. Each filter yields one output channel, so N filters give N feature maps. Early filters learn edges and colors; deeper filters learn textures, parts and objects. Convolution is typically followed by an activation (ReLU) and sometimes pooling.

What is the output size formula for a convolution?

Output = ⌊(W − K + 2P)/S⌋ + 1 where W = input size, K = kernel size, P = padding, S = stride. "Same" padding with stride 1 uses P = (K−1)/2.

What are padding, stride, and dilation?

Padding: add border pixels to preserve spatial size and edge information. Stride: step size of the filter; stride > 1 downsamples. Dilation: spaces kernel elements to enlarge the receptive field without extra parameters (atrous convolution, used in DeepLab, WaveNet).

What is the receptive field?

The region of the input that affects a particular feature. It grows with depth, kernel size, stride, pooling and dilation. Deep layers need large receptive fields to capture global context.

Max pooling vs average pooling vs global average pooling?

Max pooling keeps the strongest activation (feature presence), average pooling smooths. Global average pooling averages each feature map into one value, replacing large FC layers, reducing parameters and overfitting. Strided convolutions can replace pooling.

What is a 1×1 convolution used for?

Mixes channels at each pixel: reduces/increases channel dimension cheaply (bottlenecks in Inception/ResNet), adds non-linearity, and acts as a per-pixel fully connected layer.

What are depthwise separable convolutions?

Split a standard conv into a depthwise conv (one filter per input channel) and a pointwise 1×1 conv. Cost drops by roughly a factor of 1/Cout + 1/K² (8–9× fewer FLOPs for 3×3). Used in MobileNet, Xception, EfficientNet.

Summarize key CNN architectures.

  • LeNet-5 (1998): digit recognition; conv + pooling + FC.
  • AlexNet (2012): ReLU, dropout, GPUs, data augmentation; ImageNet breakthrough.
  • VGG: stacks of 3×3 convs; simple, deep, many parameters.
  • GoogLeNet/Inception: parallel multi-scale filters with 1×1 bottlenecks.
  • ResNet: residual connections; 50–152+ layers; bottleneck blocks.
  • DenseNet: each layer connected to all previous layers (feature reuse).
  • MobileNet / ShuffleNet: efficient mobile models.
  • EfficientNet: compound scaling of depth, width, resolution.
  • ConvNeXt: modernized CNN competitive with ViTs.

Why stack two 3×3 convolutions instead of one 5×5?

Same receptive field (5×5), fewer parameters (18C² vs 25C²), and an extra non-linearity, increasing expressiveness.

How do you apply transfer learning / fine-tuning in vision?

Load a pretrained backbone, replace the classification head. Small dataset similar to source: freeze backbone, train head. Larger or different dataset: unfreeze top layers or all, with a small learning rate (discriminative learning rates: lower for early layers). Use same input normalization as pretraining.

Image classification vs object detection vs semantic, instance and panoptic segmentation?

Classification: one label per image. Detection: bounding boxes + classes. Semantic segmentation: class per pixel (no instance separation). Instance segmentation: per-object masks. Panoptic: both semantic stuff and instance things.

Explain the R-CNN family.

R-CNN: selective search proposals → CNN on each crop → SVM; very slow. Fast R-CNN: run CNN once, RoI pooling on feature map, joint classification + box regression. Faster R-CNN: Region Proposal Network with anchors replaces selective search; end-to-end. Mask R-CNN: adds mask branch and RoIAlign (no quantization) for instance segmentation.

One-stage vs two-stage detectors? Explain YOLO.

Two-stage (Faster R-CNN): propose regions, then classify; more accurate, slower. One-stage (YOLO, SSD, RetinaNet): predict boxes and classes densely in one pass; real-time. YOLO divides the image into a grid; each cell predicts boxes, objectness, and class probabilities; later versions add anchors, multi-scale feature pyramids, and anchor-free heads. RetinaNet introduced focal loss to handle extreme foreground/background imbalance.

What are anchor boxes, IoU and Non-Max Suppression?

Anchors: predefined boxes of various scales/aspect ratios; the model predicts offsets from them. IoU: area of overlap / area of union between boxes. NMS: sort detections by confidence, keep the best, remove others with IoU above a threshold, repeat. Soft-NMS decays scores instead of removing.

How is mAP computed?

For each class, rank detections by confidence; a detection is TP if IoU ≥ threshold with an unmatched ground truth. Compute the precision-recall curve and its area (AP). mAP averages AP over classes (and over IoU thresholds 0.5:0.95 in COCO).

What is a Feature Pyramid Network (FPN)?

Combines high-resolution, low-level features with low-resolution, semantically strong features through a top-down pathway with lateral connections, giving strong multi-scale features for detecting small and large objects.

Explain U-Net and FCN for segmentation.

FCN: replaces FC layers with convs and upsamples to produce per-pixel predictions. U-Net: symmetric encoder-decoder with skip connections concatenating encoder features to decoder layers, preserving fine spatial detail; popular in medical imaging and diffusion models. Upsampling via transposed convolution or interpolation + conv. DeepLab uses atrous convolution + ASPP.

What is a transposed convolution? What are checkerboard artifacts?

A learnable upsampling operation (sometimes miscalled deconvolution) that maps a small input to a larger output. Uneven overlap when kernel size isn't divisible by stride causes checkerboard artifacts; fix with resize (nearest/bilinear) + conv.

What is a Vision Transformer (ViT)? ViT vs CNN?

ViT splits an image into patches (e.g., 16×16), linearly embeds them, adds positional embeddings and a [CLS] token, and feeds them to a Transformer encoder. Global attention from the first layer; weaker inductive bias, so needs large datasets or strong augmentation/distillation (DeiT). Swin Transformer uses shifted local windows for hierarchical features and linear complexity. CNNs are more data-efficient; ViTs scale better with data.

What is Grad-CAM?

A visualization technique that weights the last convolutional feature maps by the gradient of the class score (global-average-pooled) to produce a heatmap of image regions important for the prediction.

What are face recognition / Siamese networks?

Siamese networks share weights across two (or three) inputs to learn an embedding where similar items are close. Trained with contrastive or triplet loss (FaceNet) or margin-based softmax (ArcFace). Enables one-shot verification by comparing embedding distances.

16. RNNs, LSTMs & Sequence Models

How does a recurrent neural network work?

Processes sequences step by step, maintaining a hidden state: ht = tanh(Whht−1 + Wxxt + b). Weights are shared across time steps. Configurations: one-to-many (captioning), many-to-one (sentiment), many-to-many (tagging, translation).

What is Backpropagation Through Time (BPTT)? Truncated BPTT?

Unroll the RNN over time and backpropagate through the unrolled graph, summing gradients for shared weights. Truncated BPTT limits backprop to a fixed number of steps for efficiency and stability.

Why do vanilla RNNs struggle with long-term dependencies?

Gradients are multiplied by the recurrent weight Jacobian at every step, so they vanish or explode exponentially with sequence length, making long-range dependencies hard to learn.

Explain the LSTM architecture.

LSTM adds a cell state ct (a "conveyor belt") with gates:
Forget gate f = σ(Wf[ht−1, xt]) — what to discard.
Input gate i = σ(...) and candidate c̃ = tanh(...) — what to add.
ct = f ⊙ ct−1 + i ⊙ c̃.
Output gate o = σ(...); ht = o ⊙ tanh(ct).
The additive cell update lets gradients flow over many steps, mitigating vanishing gradients.

GRU vs LSTM?

GRU merges forget and input gates into an update gate, uses a reset gate, and has no separate cell state. Fewer parameters, faster, often similar performance; LSTM can be better on longer/more complex sequences.

What are bidirectional and stacked RNNs?

Bidirectional RNNs run one RNN forward and one backward and concatenate states, giving each position past and future context (good for tagging, not for autoregressive generation). Stacked (deep) RNNs feed one layer's hidden states as input to the next.

Explain the seq2seq encoder-decoder model.

An encoder RNN compresses the input sequence into a context vector; a decoder RNN generates the output sequence conditioned on it. The fixed-size bottleneck hurts long sequences, motivating attention (Bahdanau, Luong), where the decoder attends to all encoder states at each step.

What is teacher forcing and exposure bias?

Teacher forcing feeds the ground-truth previous token to the decoder during training, speeding convergence. At inference the model consumes its own predictions, so errors compound (exposure bias). Mitigations: scheduled sampling, sequence-level training.

Greedy decoding vs beam search?

Greedy picks the most probable token each step (fast, can miss better sequences). Beam search keeps the top-B partial sequences at each step, usually with length normalization; better for translation/summarization, but can be repetitive/bland for open-ended generation where sampling is preferred.

Why did Transformers replace RNNs?

RNNs process tokens sequentially (no parallelism across time), struggle with long dependencies, and are slow to train. Transformers use self-attention to connect all positions directly (path length O(1)), fully parallelize training, and scale better with data and compute.

17. Attention & Transformers

What is the attention mechanism?

A way to compute a weighted sum of values, where weights reflect relevance of each key to a query. It lets a model focus on relevant parts of the input dynamically instead of compressing everything into a fixed vector.

Explain scaled dot-product self-attention.

Each token embedding X is projected into Q = XWQ, K = XWK, V = XWV.
Attention(Q,K,V) = softmax(QKT / √dk) V.
Every token attends to every other token, producing context-aware representations.

Why divide by √dk?

For random vectors with unit-variance components, the dot product's variance grows with dk. Large logits push softmax into saturated regions with tiny gradients. Scaling keeps variance ~1.

What is multi-head attention and why use it?

Run h attention operations in parallel with different learned projections of smaller dimension (dmodel/h), concatenate, and project. Each head can capture different relationships (syntax, coreference, position) at roughly the same cost as one full-size head.

Describe the original Transformer architecture.

Encoder block: multi-head self-attention → add & norm → position-wise feed-forward (two linear layers with activation, typically 4× hidden size) → add & norm. Decoder block: masked self-attention → cross-attention over encoder outputs → feed-forward, each with residual + norm. Inputs: token embeddings + positional encodings. Output: linear + softmax over vocabulary.

Why are positional encodings needed? What types exist?

Self-attention is permutation-invariant, so order must be injected. Types: sinusoidal (fixed, can extrapolate somewhat), learned absolute embeddings (BERT, GPT-2), relative position encodings (T5 bias), RoPE (rotary; rotates Q/K by position-dependent angles so dot products depend on relative position; LLaMA), ALiBi (linear distance penalty on attention scores; good extrapolation).

What is masking in Transformers?

Padding mask: ignore pad tokens. Causal (look-ahead) mask: in decoders, set scores for future positions to −∞ so each token only attends to previous tokens, enabling autoregressive training in parallel.

Self-attention vs cross-attention?

Self-attention: Q, K, V come from the same sequence. Cross-attention: Q from one sequence (decoder), K and V from another (encoder output, image features, or text conditioning in diffusion models).

What is the computational complexity of self-attention, and how is it reduced?

O(n²·d) time and O(n²) memory in sequence length n. Reductions: sparse/local attention (Longformer, BigBird), low-rank/linear attention (Linformer, Performer), sliding windows, FlashAttention (IO-aware exact attention computed in tiles, avoiding materializing the n×n matrix), multi-query and grouped-query attention (fewer K/V heads to shrink KV cache).

Walk through the tensor shapes in multi-head attention. How many parameters does a Transformer layer have?

Input X: (B, n, dmodel). Project to Q, K, V and split into h heads: (B, h, n, dk) with dk = dmodel/h. Scores QKT: (B, h, n, n) — the n² term. Weights × V: (B, h, n, dk); concatenate heads back to (B, n, dmodel) and apply WO. Parameters per layer (ignoring biases and norms): attention 4·dmodel² (WQ, WK, WV, WO) + feed-forward 2·dmodel·dff = 8·dmodel² when dff = 4·dmodel, so about 12·dmodel² per layer.

Explain BERT pretraining.

Masked Language Modeling: mask 15% of tokens (of these 80% [MASK], 10% random, 10% unchanged) and predict them using bidirectional context. Next Sentence Prediction: predict if sentence B follows A (later shown to be of little value; RoBERTa dropped it and trained longer with dynamic masking). Uses [CLS] for sentence-level tasks and [SEP] between segments; WordPiece tokenization.

What is the role of the feed-forward network in a Transformer block?

Applied independently to each position, it adds non-linear transformation capacity and holds most parameters; it is thought to store factual "key-value memories." Variants: GeLU FFN, SwiGLU (gated), and Mixture-of-Experts FFNs.

18. Natural Language Processing

What are the common text preprocessing steps?

Lowercasing, tokenization, removing punctuation/stop words/HTML, handling numbers and emojis, stemming or lemmatization, spelling normalization. For modern Transformers, minimal preprocessing is used: the model's own subword tokenizer handles raw text.

Stemming vs lemmatization?

Stemming chops suffixes heuristically ("studies" → "studi"; Porter, Snowball); fast but crude. Lemmatization uses vocabulary and POS to return dictionary forms ("studies" → "study", "better" → "good"); more accurate, slower.

Explain Bag-of-Words and TF-IDF.

BoW represents a document by word counts, ignoring order. TF-IDF weights term frequency by inverse document frequency: tfidf = tf(t,d) × log(N/df(t)), down-weighting common words. Both are sparse and lose semantics/order; n-grams capture some local order. Still strong baselines with logistic regression/Naive Bayes; BM25 is a TF-IDF-like ranking function for search.

What are word embeddings and why are they better than one-hot encoding?

One-hot vectors are sparse, vocabulary-sized, and every pair of words is equally distant, so no meaning is captured. Word embeddings are dense, low-dimensional (e.g., 100–1024) vectors learned so that words used in similar contexts are close together, capturing semantic and syntactic relationships, generalizing better and using less memory.

Explain word2vec (CBOW and Skip-gram).

Learns dense word vectors from context. CBOW predicts a word from surrounding words (faster, good for frequent words). Skip-gram predicts context words from the center word (better for rare words). Training efficiency via negative sampling (distinguish true context pairs from random pairs) or hierarchical softmax. Embeddings capture analogies (king − man + woman ≈ queen).

word2vec vs GloVe vs FastText?

word2vec: predictive, local context windows. GloVe: factorizes global word co-occurrence statistics (log counts). FastText: represents words as sums of character n-grams, so it handles out-of-vocabulary words and morphology. All produce static embeddings (one vector per word regardless of context).

Static vs contextual embeddings?

Static embeddings give "bank" the same vector in "river bank" and "bank account". Contextual embeddings (ELMo, BERT, GPT) compute token representations depending on the whole sentence, handling polysemy.

What is cosine similarity and why is it used for text?

cos θ = A·B / (||A|| ||B||), ranging from −1 to 1 (0 to 1 for non-negative vectors like TF-IDF). It measures direction rather than magnitude, so document length doesn't dominate. Used for document similarity, semantic search, deduplication and recommendations. For L2-normalized vectors it equals the dot product.

Explain subword tokenization: BPE, WordPiece, SentencePiece.

Subwords balance vocabulary size and OOV handling. BPE: start from characters/bytes and iteratively merge the most frequent adjacent pair (GPT uses byte-level BPE). WordPiece: merges pairs that maximize training-data likelihood (BERT; "##" continuation prefix). Unigram LM: starts large and prunes tokens by likelihood. SentencePiece: library that treats text as raw stream including spaces (▁), language-independent, supports BPE and unigram (T5, LLaMA).

What is perplexity?

exp of the average negative log-likelihood per token; the effective number of choices the model is uncertain among. Lower is better; only comparable across models with the same tokenizer/vocabulary.

What are common NLP tasks?

Text classification/sentiment, Named Entity Recognition, POS tagging, dependency parsing, question answering (extractive/generative), summarization (extractive/abstractive), machine translation, natural language inference, semantic similarity, coreference resolution, topic modeling, information extraction, text generation.

How is NER modeled?

As token classification with BIO/BIOES tags (B-PER, I-PER, O). Classic: CRF or BiLSTM-CRF (CRF enforces valid tag transitions). Modern: fine-tuned BERT-style token classifiers or LLM prompting. Evaluate with entity-level precision/recall/F1.

Explain BLEU and ROUGE.

BLEU: geometric mean of modified n-gram precisions (1–4) against references with a brevity penalty; for translation. ROUGE: recall-oriented n-gram (ROUGE-N) or longest common subsequence (ROUGE-L) overlap; for summarization. Both miss semantics/paraphrases; complemented by BERTScore, COMET, or human/LLM judges.

How would you build a text classifier today?

Baseline TF-IDF + logistic regression; then fine-tune a pretrained encoder (e.g., DeBERTa/RoBERTa) with a classification head; or use sentence embeddings + light classifier; or zero/few-shot LLM prompting if labeled data is scarce. Handle imbalance, evaluate with F1, and analyze errors.

How are sentence embeddings created and used?

Sentence-BERT fine-tunes a Siamese BERT with contrastive/NLI objectives and mean pooling so cosine similarity reflects semantic similarity. Used for semantic search, clustering, deduplication, and RAG retrieval. Bi-encoders are fast (precompute embeddings); cross-encoders jointly encode pairs and are more accurate for re-ranking.

19. MLOps, Deployment & Efficiency

What is MLOps and what does an ML lifecycle look like?

Practices that combine ML, DevOps and data engineering to reliably build, deploy and maintain models. Lifecycle: data ingestion/validation → feature engineering → training & experiment tracking → evaluation & validation → model registry → deployment → monitoring → retraining (CI/CD/CT: continuous training). Tools: MLflow, Kubeflow, Azure ML, SageMaker, Vertex AI, DVC, Airflow, Feast, Weights & Biases.

Batch vs real-time (online) vs streaming vs edge inference?

Batch: scheduled predictions stored for later (nightly churn scores); simple, high throughput. Online: REST/gRPC endpoint with low latency per request (fraud check at payment). Streaming: process events continuously (Kafka + Flink). Edge: run on device for privacy/latency/offline (mobile, IoT) using compressed models.

What is data drift vs concept drift? How do you monitor them?

Data (covariate) drift: P(X) changes (new user demographics). Concept drift: P(Y|X) changes (fraud patterns evolve). Label/prior drift: P(Y) changes. Monitor input feature distributions (PSI, KL/JS divergence, KS test, Wasserstein), prediction distributions, data quality (nulls, schema), and actual performance when labels arrive. Respond with alerts, retraining (scheduled or triggered), and fallbacks.

What is training-serving skew?

Differences between training and production data or feature computation (different code paths, time windows, preprocessing), causing degraded performance. Prevent with shared feature pipelines, feature stores, logging production features for training, and data validation.

What is a feature store?

A centralized system to define, compute, store and serve features consistently for training (offline store, point-in-time correct joins) and inference (low-latency online store). Enables reuse and avoids training-serving skew (Feast, Tecton, Databricks, SageMaker Feature Store).

How do you ensure reproducibility in ML?

Version code (Git), data (DVC, lakeFS, snapshots), and models (registry); track experiments, hyperparameters and metrics; fix random seeds; pin dependency versions and use containers; log environment and hardware details; automate pipelines.

What deployment strategies are used for models?

Shadow deployment (new model runs on live traffic without affecting users), canary release (small % of traffic), A/B testing, blue-green deployment (switch between environments, quick rollback), multi-armed bandit routing. Always keep rollback paths.

How do you reduce model size and latency?

Quantization (INT8/INT4), pruning (unstructured weights or structured channels/heads), knowledge distillation, efficient architectures (MobileNet, DistilBERT), operator fusion and compilers (ONNX Runtime, TensorRT, OpenVINO, TorchScript/torch.compile), batching requests, caching, hardware acceleration (GPU/TPU/NPU), and early-exit models.

What is ONNX?

Open Neural Network Exchange: an open format to represent models so they can move between frameworks (PyTorch, TensorFlow, scikit-learn) and run in optimized runtimes (ONNX Runtime) across hardware.

How would you serve a model as an API?

Wrap the model in a web service (FastAPI/Flask, TorchServe, Triton, BentoML, KServe), load the model once at startup, validate inputs (schema), batch where possible, containerize with Docker, deploy on Kubernetes/managed endpoints with autoscaling, add authentication, logging, metrics (latency, throughput, errors), and health checks.

What should you monitor for a production ML model?

Operational: latency, throughput, errors, resource usage, cost. Data: schema, missing values, feature distributions, drift. Model: prediction distribution, confidence, performance metrics vs ground truth, fairness across segments. Business KPIs.

What is CI/CD/CT in machine learning? What is a model registry?

CI: on every change, run code tests plus data validation (schema, ranges), feature unit tests and quick training checks. CD: automatically package and deploy the model service once it passes evaluation gates (e.g., beats the current production model on a holdout set). CT (continuous training): retrain automatically on a schedule or when drift is detected. A model registry stores versioned models with metadata, metrics, lineage and stage (staging/production/archived), enabling approval workflows and rollback.

20. Scenario-Based & System Design Questions

Your model performs great offline but poorly in production. What do you check?

Data leakage in offline evaluation; training-serving skew in feature computation; data/concept drift; different preprocessing or library versions; label definition mismatch; offline metric not aligned with business metric; selection bias in training data; latency timeouts causing fallbacks; bugs in input parsing. Compare logged production features against training distributions and replay production data through the offline pipeline.

Design a fraud detection system.

Extremely imbalanced, adversarial, and real-time. Features: transaction amount, velocity (counts in last 1h/24h), device/IP, geolocation mismatch, merchant risk, user history aggregates, graph features (shared devices/cards). Model: gradient boosting baseline + rules; possibly graph/sequence models. Handle imbalance with class weights and threshold tuning; optimize precision at a fixed recall or expected cost. Time-based validation. Low-latency online feature store. Delayed labels (chargebacks) → monitor drift, retrain frequently; human review queue for medium-risk scores; feedback loop.

You have very little labeled data. What do you do?

Use transfer learning / pretrained models; data augmentation; few-shot or zero-shot LLM prompting; semi-supervised learning and pseudo-labeling; active learning to label the most valuable samples; weak supervision (labeling functions, Snorkel); synthetic data generation; simpler models with strong regularization; cross-validation for reliable estimates.

Your dataset is too big to fit in memory. How do you train?

Stream data in mini-batches (data loaders, generators), use online/incremental learners (SGD, partial_fit), sample intelligently, use efficient formats (Parquet, memory mapping), out-of-core tools (Dask, Spark MLlib, Vaex), distributed training, or reduce features/precision.

Training loss decreases but validation loss increases. What's happening and what do you do?

Overfitting. Use early stopping, regularization (dropout, weight decay), augmentation, more data, smaller model, check for train/validation distribution mismatch or leakage between them.

Loss becomes NaN during training. What could cause it?

Learning rate too high, exploding gradients, log(0) or division by zero in custom losses, FP16 overflow/underflow without loss scaling, bad input data (NaN/inf values), and unstable operations (use log-softmax, BCEWithLogits). Fix with gradient clipping, lower LR, numerical-stable functions, data checks.

Your model's performance has plateaued. How would you improve it?

  1. Error analysis: inspect misclassified samples, slice performance by segment, look at the confusion matrix to find patterns.
  2. Data: fix label noise, collect more or more representative data, augment, rebalance classes.
  3. Features: engineer domain features, interactions, aggregations; remove noisy or leaky ones.
  4. Model: try stronger algorithms, tune hyperparameters, use transfer learning, ensemble diverse models.
  5. Objective: make sure the loss and metric match the business goal; tune the decision threshold.
  6. Check for underfitting vs overfitting with learning curves to decide which direction to go.

How do you handle unseen categories or missing features at inference time?

Design for it during training: map rare and unseen categories to an "Other/Unknown" bucket (e.g., OneHotEncoder(handle_unknown='ignore')), use hashing or embeddings with an unknown token, impute missing values with the same fitted imputer and add missing-indicator flags, and validate inputs against a schema. Log and monitor how often this happens, since a rise signals data drift or upstream bugs.

How do you detect and mitigate bias (unfairness) in a model?

Sources: historical bias in data, under-representation of groups, biased labels, proxy features (zip code standing in for ethnicity), feedback loops. Detect: evaluate metrics sliced by group and compare fairness measures such as demographic parity (equal positive rates), equal opportunity (equal recall/TPR) and equalized odds (equal TPR and FPR). Mitigate: collect more representative data, reweight or resample, review proxy features, add fairness constraints during training, or adjust thresholds per group; document with model cards and monitor after deployment. Fairness definitions can conflict, so choose with stakeholders.

How would you explain a complex model to non-technical stakeholders?

Focus on business impact and decisions, not algorithms. Use simple analogies, global drivers (top features via SHAP), concrete example predictions with reasons, confidence/limitations, error trade-offs in business terms (cost of false positives vs negatives), and visualizations.

Design a search ranking / recommendation system for an e-commerce site.

Clarify objectives (CTR, conversion, revenue, diversity). Data: queries, impressions, clicks, purchases, item catalog. Architecture: candidate retrieval (BM25 + two-tower embeddings + ANN) → ranking (learning-to-rank with GBDT/LambdaMART or deep model on user, item, query and context features) → re-ranking (business rules, diversity, freshness). Handle position bias in click data, cold start, latency budgets. Offline metrics: NDCG, MRR, recall@k; online A/B test on business KPIs.

Design a customer churn prediction system.

Define churn precisely and the prediction horizon; build snapshot-based training data with features computed only from data before the snapshot (usage trends, support tickets, billing, tenure, engagement). Model with gradient boosting; evaluate with PR-AUC and lift/top-decile capture; calibrate probabilities; use SHAP for reasons to guide retention actions; consider uplift modeling to target customers who can be persuaded; deploy as batch scoring with monitoring.

How would you choose between a simple model and a complex model?

Compare on validation performance relative to business value, latency and cost constraints, interpretability/regulatory needs, data size, maintenance burden and robustness. If the complex model's gain is marginal, prefer the simpler one.

How do you handle a model whose predictions degrade over time?

Set up monitoring for drift and performance; investigate root cause (data pipeline bug vs genuine drift); retrain on recent data (sliding window or weighted), consider online learning, add features capturing the change, set retraining triggers, and keep a fallback model or rules.

Your model shows 99% accuracy. Is it a good model?

Not necessarily. Check class balance (a majority-class baseline may also score 99%), look at per-class precision/recall and the confusion matrix, check for data leakage (results that look too good), verify the split (duplicates across sets, time ordering), test on truly held-out or out-of-time data, and evaluate against the business cost of errors.

You have more features than samples (p >> n). What do you do?

The model can easily overfit and OLS has no unique solution (XTX is singular). Use regularization (Lasso, Ridge, Elastic Net), feature selection, dimensionality reduction (PCA), simpler models, domain knowledge to drop irrelevant features, careful (nested) cross-validation, and collect more data if possible.

Training and test data come from different distributions. How do you detect and handle it?

Detect with adversarial validation: label training rows 0 and test rows 1, train a classifier; AUC near 0.5 means similar distributions, high AUC means shift, and its feature importances show which features drift. Handle: drop or transform shifted features, weight training samples by how test-like they are (importance weighting), build a validation set that resembles the test data, apply domain adaptation, or collect more representative data.

import numpy as np

def classification_metrics(y_true, y_pred):
    tp = np.sum((y_true == 1) & (y_pred == 1))
    fp = np.sum((y_true == 0) & (y_pred == 1))
    fn = np.sum((y_true == 1) & (y_pred == 0))
    tn = np.sum((y_true == 0) & (y_pred == 0))
    precision = tp / (tp + fp) if tp + fp else 0.0
    recall = tp / (tp + fn) if tp + fn else 0.0
    f1 = 2 * precision * recall / (precision + recall) if precision + recall else 0.0
    accuracy = (tp + tn) / len(y_true)
    return accuracy, precision, recall, f1

def linear_regression_gd(X, y, lr=0.01, epochs=1000):
    n, d = X.shape
    w, b = np.zeros(d), 0.0
    for _ in range(epochs):
        err = X @ w + b - y
        w -= lr * (2 / n) * (X.T @ err)
        b -= lr * (2 / n) * err.sum()
    return w, b

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def logistic_regression(X, y, lr=0.1, epochs=1000, l2=0.0):
    n, d = X.shape
    w, b = np.zeros(d), 0.0
    for _ in range(epochs):
        p = sigmoid(X @ w + b)
        w -= lr * (X.T @ (p - y) / n + l2 * w)
        b -= lr * (p - y).mean()
    return w, b

def predict(X, w, b, threshold=0.5):
    return (sigmoid(X @ w + b) >= threshold).astype(int)

The gradient XT(p − y)/n comes from the derivative of log loss with a sigmoid output.

def kmeans(X, k, iters=100, seed=0):
    rng = np.random.default_rng(seed)
    centroids = X[rng.choice(len(X), k, replace=False)]
    for _ in range(iters):
        dists = np.linalg.norm(X[:, None, :] - centroids[None, :, :], axis=2)
        labels = dists.argmin(axis=1)
        new = np.array([X[labels == j].mean(axis=0) if np.any(labels == j) else centroids[j]
                        for j in range(k)])
        if np.allclose(new, centroids):
            break
        centroids = new
    return centroids, labels

Compute Gini impurity and find the best split for one feature.

def gini(y):
    _, counts = np.unique(y, return_counts=True)
    p = counts / counts.sum()
    return 1 - np.sum(p ** 2)

def best_split(x, y):
    best_t, best_score = None, np.inf
    for t in np.unique(x)[:-1]:
        left, right = y[x <= t], y[x > t]
        score = (len(left) * gini(left) + len(right) * gini(right)) / len(y)
        if score < best_score:
            best_t, best_score = t, score
    return best_t, best_score

from scipy.stats import rankdata

def roc_auc(y_true, scores):
    ranks = rankdata(scores)                      # average ranks handle ties
    n_pos = np.sum(y_true == 1)
    n_neg = len(y_true) - n_pos
    return (ranks[y_true == 1].sum() - n_pos * (n_pos + 1) / 2) / (n_pos * n_neg)

Uses the Mann-Whitney U statistic: AUC is the probability a random positive outranks a random negative.

Implement a numerically stable softmax and cross-entropy.

def softmax(z):
    z = z - z.max(axis=-1, keepdims=True)
    e = np.exp(z)
    return e / e.sum(axis=-1, keepdims=True)

def cross_entropy(logits, y):
    z = logits - logits.max(axis=1, keepdims=True)
    log_probs = z - np.log(np.exp(z).sum(axis=1, keepdims=True))
    return -log_probs[np.arange(len(y)), y].mean()

Subtracting the max avoids overflow in exp without changing the result (log-sum-exp trick).

def scaled_dot_product_attention(Q, K, V, mask=None):

    scores = Q @ K.swapaxes(-1, -2) / np.sqrt(d_k)
    if mask is not None:
        scores = np.where(mask, scores, -1e9)     # mask: True = may attend
    weights = softmax(scores)

Implement IoU and Non-Max Suppression.

def iou(a, b):                                    # boxes as [x1, y1, x2, y2]
    x1, y1 = max(a[0], b[0]), max(a[1], b[1])
    x2, y2 = min(a[2], b[2]), min(a[3], b[3])
    inter = max(0, x2 - x1) * max(0, y2 - y1)
    area_a = (a[2] - a[0]) * (a[3] - a[1])
    area_b = (b[2] - b[0]) * (b[3] - b[1])
    return inter / (area_a + area_b - inter + 1e-9)

def nms(boxes, scores, iou_thresh=0.5):
    order = list(np.argsort(scores)[::-1])
    keep = []
    while order:
        i = order.pop(0)
        keep.append(i)
        order = [j for j in order if iou(boxes[i], boxes[j]) < iou_thresh]
    return keep
